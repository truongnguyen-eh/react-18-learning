# React 18 Learning Repository

A comprehensive learning resource for React 18 features and best practices.

## 🚀 Getting Started

1. Clone this repository
2. Install dependencies:
```bash
npm install
```

## 📚 Topics Covered

Each folder in this repository focuses on a specific React 18 feature:

- `concurrency/` - React 18's concurrent features
  - `transitions` - Start Transition API
  - `suspense` - Suspense and data fetching
  - `streaming` - Server-side streaming

## 🛠 Usage

To run a specific topic:

```bash
npm start {folder}:{topic}
```

### Examples:

```bash
# Run transitions example
npm start concurrency:transitions

# Run suspense example
npm start concurrency:suspense
```
